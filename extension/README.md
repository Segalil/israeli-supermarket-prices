# ליםSlim — תוסף העברת סל לרשתות

מעביר את רשימת הקניות מהאתר אל עגלת הקנייה באתר הרשת שנבחרה — **בתוך החשבון של
המשתמש ובשליטתו המלאה**. התוסף לא שומר סיסמאות, לא מתחבר בשם המשתמש ולא שולח
מידע לשום שרת: הוא קורא את רשימת ההעברה שהאתר הכין, ומלווה את המשתמש באתר
הרשת — חיפוש כל פריט (לפי ברקוד ברשתות שתומכות) והוספה לעגלה, אוטומטית כשמבנה
הדף מזוהה או בליווי ידני כשלא.

## איך זה עובד
1. באתר ליםSlim בוחרים רשת ולוחצים "בניית ההזמנה" — האתר שומר את רשימת ההעברה.
2. התוסף מזהה את הרשימה, ובאתר הרשת מציג פאנל צף עם הפריטים.
3. "▶ מילוי אוטומטי" עובר פריט-פריט: חיפוש → זיהוי כפתור ההוספה → הוספה בכמות
   הנכונה. כשמבנה הדף לא מזוהה (הרשתות מעדכנות את האתרים) הפאנל עובר למצב
   מלווה: קישור חיפוש + "✓ הוספתי" ידני.
4. ההתקדמות נשמרת בין דפים; בסיום — בודקים את העגלה ומשלמים מול הרשת כרגיל.

## רשתות נתמכות כרגע
- שופרסל (חיפוש לפי ברקוד)
- רמי לוי (חיפוש לפי ברקוד)

הוספת רשת = קובץ אחד ב־`chains/` עם תבנית חיפוש וסלקטורים + רישום ב־manifest.

## התקנה לפיתוח (Load unpacked)
1. `chrome://extensions` → הפעלת "Developer mode"
2. "Load unpacked" → בחירת התיקייה `extension/`

## פרסום
להפצה רחבה נדרש חשבון מפתח ב־Chrome Web Store (תשלום חד-פעמי של $5) והעלאת
התיקייה כ־zip. מומלץ להוסיף אייקונים (128/48/16px) לפני הפרסום.

## הערות
- הסלקטורים ב־`chains/*.js` הם מול מבנה האתרים הנוכחי ועשויים להישבר כשהרשתות
  מעדכנות עיצוב — מצב הליווי הידני ממשיך לעבוד תמיד.
- אוטומציה בתוך סשן של המשתמש, ביוזמתו, על חשבונו שלו — שקולה ללחיצות שלו.
  בכל מקרה מומלץ לוודא מול תנאי השימוש של כל רשת לפני הפצה מסחרית רחבה.
