# israeli-supermarket-prices

בניית דאטהבייס (Excel + CSV) של מחירי מוצרים מחנויות ה**אונליין** של רשתות המזון
המובילות בישראל, מתוך קבצי **שקיפות המחירים** הרשמיים (חוק המזון). הנתונים חוקיים
ופומביים — כל רשת קמעונאית גדולה מחויבת לפרסם אותם.

> Build an Excel/CSV price database from Israel's official supermarket
> price-transparency files, for the online stores of the leading chains.

## Features
- מוריד את קבצי `PriceFull` **ו‑`PromoFull`** הרשמיים דרך [`il-supermarket-scraper`](https://pypi.org/project/il-supermarket-scraper/).
- מזהה אוטומטית את חנות האונליין של כל רשת (לפי קובץ הסניפים) ומוריד **בדיוק את הקובץ
  של החנות הזו** (סינון `store_id`); אם לא זוהתה — נלקח סניף מייצג.
- מפענח את וריאציות סכימת ה‑XML (`<Item>` / `<Product>` / `<ItemNm>` של רמי לוי,
  מבצעים בשתי הסכימות), כולל `gzip` וקידוד `windows-1255`.
- מייצא ל‑CSV (UTF‑8 BOM, נפתח נכון באקסל), ל‑XLSX, ול‑CSV מבצעים.
- **סלים=Slim** — אתר שבו בונים רשימת קניות ומשווים את עלות הסל המלא בין הרשתות (ראו למטה).

> **חשוב — מאיפה מריצים:** חלק מאתרי הפרסום של הרשתות (למשל `laibcatalog.co.il` של
> ויקטורי) חוסמים כתובות IP זרות/ענן. מ‑GitHub Actions (ארה"ב) נאספות רק חלק
> מהרשתות; **הרצה ממחשב בישראל אוספת את כל 6 הרשתות המובילות.** ה‑workflow היומי
> שומר כל מה שהצליח, והרצה מקומית משלימה את השאר.

## 🛒 האתר — סלים=Slim
אתר סטטי (`site/`) בעיצוב "Slim": רשימה אחת, הסל הזול ביותר. המסכים:
- **מסך פתיחה** — בחירת רשתות להשוואה וכתובת (עם **השלמה אוטומטית**), עם תצוגה חיה
  של הסל והרשת הזולה.
- **בניית רשימה** — חיפוש בקטלוג האמיתי (שם/ברקוד), מוצרים נפוצים עם **תמונות מוצר**
  (Open Food Facts לפי ברקוד; אימוג׳י כגיבוי), כמויות, ועדיפות דירוג.
- **השוואה** — דירוג הרשתות עם "הכי משתלם", **מבצעים אונליין בתוך החישוב**:
  מבצעים ללא תנאים מוחלים אוטומטית, ומבצעי כמות ("2 ב־20") מחושבים לפי חבילות —
  כמות שמגיעה לסף המבצע מקבלת את מחיר המבצע, והשאר במחיר רגיל. מוצרים חסרים,
  מינימום, **בדיקת משלוח לכתובת** (משוער), **חלון המשלוח הקרוב** (משוער) ומצב
  **פיצול חכם**.
- **השלמת מבצעים 💡** — כשחסרות יחידות כדי להגיע למבצע כמות, האתר מציע להוסיף
  אותן: כמה זה יעלה, כמה חוסכים מול מחיר רגיל, ולחיצה אחת משלימה את הכמות.
- **פירוט סל** — מחירי כל מוצר כולל מחיר מבצע, **חלופות אמיתיות למוצרים חסרים**,
  וכרטיס סיכום להזמנה.
- **יצירת הזמנה** — הרשימה מועתקת ללוח וחנות האונליין נפתחת; קישורי חיפוש ישירים
  לכל מוצר. ההוספה הסופית לסל והתשלום באתר הרשת.
- **רשימות שמורות** (כולל איחוד) **ופרופיל מקומי** — הכול נשמר בדפדפן בלבד.

**מודל איחוד מוצרים:** מוצרים מאוחדים בין רשתות לפי ברקוד, ובנוסף לפי **חתימת שם**
(סדר מילים לא משנה: "חלב תנובה 3%" = "3% חלב תנובה") — רק כששתי הרשומות לא קיימות
באותה רשת, כדי שלא לאחד שני מוצרים שונים באמת.

דמי המשלוח, המינימום, חלונות האספקה ואזורי החלוקה הם הערכות הניתנות לעריכה
ב־`CHAIN_META` שב־[`site/app.js`](site/app.js); המחירים והמבצעים אמיתיים מנתוני השקיפות.

הרצה מקומית:
```bash
python build_site_data.py                 # יוצר site/data/products.json.gz מהצילום האחרון ב-data/
python -m http.server 8737 --directory site
# ואז לגלוש אל http://localhost:8737
```

פריסה אוטומטית: ה‑workflow‏ `deploy-pages.yml` בונה את הדאטה מהצילום היומי האחרון
ומפרסם ל‑GitHub Pages אחרי כל צילום יומי (הגדרה חד‑פעמית: Settings → Pages →
Source: **GitHub Actions**).

## Install
```bash
pip install -r requirements.txt
```
Requires Python 3.9+.

## Usage
```bash
python build_price_db.py                         # 8 leading chains, online store
python build_price_db.py --chains SHUFERSAL RAMI_LEVY
python build_price_db.py --all-stores            # every branch (very large!)
```
פלט נכתב לתיקיית `out/`:
- `israeli_prices_YYYYMMDD.csv`
- `israeli_prices_YYYYMMDD.xlsx` (גיליונות `מחירים` + `סיכום`)

## Chains included by default
שופרסל · רמי לוי · ויקטורי · יינות ביתן/קרפור · יוחננוף · טיב טעם · אושר עד · חצי חינם

מפתחות הרשתות מוגדרים במילון `LEADING_CHAINS` שבתוך `build_price_db.py` וניתן להרחיב
אותם לכל רשת שהספרייה תומכת בה.
